# ミニ家庭菜園管理アプリ
　本アプリは、小さな家庭菜園を管理するためのAndroidアプリである。
 
　2026年春、自宅の庭を整備したことをきっかけに、小さな家庭菜園を始めた。 
しかし、野菜の生育が進むにつれて、施肥や整枝、収穫日などを管理しきれず、結果として作業漏れや対応の遅れが発生した。 
　このアプリで、日々の記録を簡単に管理することで、その情報を栽培の振り返りや翌年度の栽培計画に活用できるようにすることを目的とする。

　対象は自宅の庭や小規模な畑で複数の野菜を栽培しており、水やり・施肥・収穫などの作業記録を手軽に管理したいユーザーである。

## 主な機能
### １：作物の新規登録、編集、削除
　　作物情報を登録し、栽培情報を管理できる。  
 　登録後、ゲーム画面のような畑とアイコンで、栽培中の作物を視覚的に確認できる。
 
### ２：作業記録の登録
　　水やり、施肥、虫害、葉枯れ、収穫等の作業を、チェックボックスで簡単に記録できる。  
 　また、全ての作物への水やりを一括記録できる。

### ３：作業記録の確認
　　登録作物ごとに、過去の作業記録を確認できる。
